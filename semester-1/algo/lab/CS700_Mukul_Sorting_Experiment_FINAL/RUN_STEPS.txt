# BABY STEPS — RUNNING THE FINAL PROJECT

## STEP 1 — Extract

Extract:

CS700_Mukul_Sorting_Experiment_FINAL.zip

Open the extracted folder in VS Code.

You should see:

src/
datasets/
results/
graphs/
plot_results.py
README_VIVA.md
RUN_STEPS.txt

---

## STEP 2 — OPEN TERMINAL

In VS Code:

Terminal → New Terminal

The terminal should be at:

...\CS700_Mukul_Sorting_Experiment_FINAL>

If it ends with:

...\src>

run:

cd ..

---

## STEP 3 — CHECK G++

Run:

g++ --version

If a version appears, continue.

---

## STEP 4 — COMPILE

Run exactly:

g++ -std=c++17 -O2 src/main.cpp -o sorting.exe

No output/error means compilation succeeded.

---

## STEP 5 — RUN

Run:

.\sorting.exe

---

## STEP 6 — FIRST SMALL CHECK

Choose:

1

This tests only First-Pivot QuickSort.

When asked:

Number of rounds [5]:

enter:

1

This is just a quick sanity check.

---

## STEP 7 — QUICK SORT STUDY

Run the program again.

Choose:

5

Then enter:

5

This runs the COMPLETE experiment.
