CS-700 ASSIGNMENT 2
Simple Experimental Sorting Project

IMPORTANT
---------
Input files are already included in input/.
They are NOT generated by the C++ program.

Datasets:
10,000
20,000
50,000
100,000
200,000

Types:
random
sorted
reverse

Stage 1:
Compare:
- First-element QuickSort
- Random-pivot QuickSort
- Median-of-three QuickSort

Stage 2:
Compare:
- Bubble Sort
- Insertion Sort
- Merge Sort
- QuickSort (median-of-three)
- Heap Sort
- Radix Sort

The O(n^2) algorithms (Bubble and Insertion) are tested only up to
n = 20,000. Faster algorithms continue to n = 200,000.

Each experiment is repeated 5 times and the average is used for graphs.

RUNNING
-------
Open the project root in VS Code.

Compile:
g++ -std=c++17 -O2 src/main.cpp -o sorting.exe

Run:
.\sorting.exe

Then create graphs:
python plot_results.py

Results:
results/results.csv
(The results/ folder is created automatically when the program runs.)

Graphs:
graphs/
