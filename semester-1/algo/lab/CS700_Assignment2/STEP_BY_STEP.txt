BABY-STEP RUN GUIDE

1. Extract the ZIP.

2. Open the folder "CS700_Assignment2_Final_2Lakh" in VS Code.

3. Make sure the terminal is at the project ROOT:
   ...\CS700_Assignment2_Final_2Lakh>

   NOT:
   ...\src>

4. Check C++:
   g++ --version

5. Check Python:
   python --version

6. Install graph libraries ONCE:
   python -m pip install pandas matplotlib

7. You DO NOT need to generate inputs.
   They are already saved in:
   input/random/
   input/sorted/
   input/reverse/

8. Compile:
   g++ -std=c++17 -O2 .\src\main.cpp -o sorting.exe

9. Run:
   .\sorting.exe

10. Wait until you see:
    EXPERIMENT COMPLETE!

11. Open:
    results/results.csv
    (The results/ folder is created automatically by sorting.exe.)

12. Create graphs:
    python plot_results.py

13. Open:
    graphs/
